# calc 言語仕様

`calc` は ASTro 最小チュートリアル用の電卓言語。**整数の四則演算と剰余だけ**を
扱う。文・関数・変数・型は無い。式 1 つを評価して結果を返す、それだけ。

## 値

- 32bit 符号付き整数 (`int32_t`) のみ。
- オーバーフロー検査なし (C の `int32_t` のオーバーフロー挙動と同じ)。

## 式

### リテラル

10 進数の整数のみ。負号は単項プレフィクスとしてリテラルに付く。

```
0
42
-3
```

(16 進・2 進・浮動小数・指数表記はなし。)

### 二項演算

5 つだけ。すべて整数 → 整数。

| 演算 | 意味 |
|---|---|
| `a + b` | 加算 |
| `a - b` | 減算 |
| `a * b` | 乗算 |
| `a / b` | 整数除算 (C の `/` と同じ; ゼロ除算は未定義) |
| `a % b` | 剰余 (C の `%` と同じ) |

### 括弧

`(expr)` で評価順を変更できる。

```
(10 - 3) % 4
```

### 優先順位・結合性

C の式と同じ:

- `* / %` は `+ -` より優先。
- 同優先度は左結合 (`a - b - c` は `(a - b) - c`)。

## 文法 (BNF)

```
expr   = term   (('+' | '-') term)*
term   = factor (('*' | '/' | '%') factor)*
factor = NUMBER | '(' expr ')'
```

実装は `main.c` の手書き再帰下降パーサ (約 60 行)。コメント・識別子・
代入・関数・空白以外の構文は一切無い。

## 実行モデル

- `./calc -e EXPR` あるいは REPL の各行が、上記 1 つの式を評価する単位。
- 結果は最後に評価された二項演算 (または単独リテラル) の値。
- 副作用無し (I/O / 状態変更なし)。

## 例

```
$ ./calc -e '1 + 2 * 3'
7

$ ./calc -e '(10 - 3) % 4'
3

$ ./calc
calc> -5 + 8
=> 3
calc> 100 / 7
=> 14
calc> 100 % 7
=> 2
```

## 意図的に削った機能

`calc` は ASTro フレームワーク自身を見せるための最小例なので、以下は
**意図的に持たない**:

- 変数 / 代入 / `let`
- 関数 / 名前付き定数
- 浮動小数 / 文字列 / 真偽値
- 比較・論理演算・分岐 (`if` 等)
- ループ / 入出力

これら全部入りの「実言語」サンプルは [`naruby`](../../naruby/) や
[`ascheme`](../../ascheme/) 等を参照。
