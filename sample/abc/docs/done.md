# abc 実装済み機能

意味論の詳細は [spec.md](spec.md)、制限は [todo.md](todo.md)。

## 数・演算

- 任意精度十進固定小数点 (GMP 仮数 + `scale`)。末尾ゼロ保持。
- **fixnum 即値**: scale 0・62bit 整数は LSB タグ即値で GMP/GC を回避 (`+ - * / % cmp`
  は native long fast path)。小整数ループで bc より速い (詳細は [perf.md](perf.md))。
- 四則 `+ - * /`、剰余 `%`、冪 `^` (整数指数・負指数)。
- 単項マイナス、比較 `== != < <= > >=` (連鎖可)、論理 `&& || !` (短絡)。
- POSIX bc の scale 伝播規則を全演算で再現 (加減/乗/除/剰余/冪/sqrt)。
- 0 方向への切り捨て。

## 変数・代入

- スカラ変数 (グローバル)、未定義変数は 0。
- 代入 `=`、複合代入 `+= -= *= /= %= ^=`。
- 前置/後置インクリメント・デクリメント `++ --`。
- 代入式の値伝播 (`a = b = c = 1`)、代入文は非表示・`(x=5)` は表示。
- 特殊変数 `scale` / `ibase` / `obase` / `last` (`.`)。

## 配列

- `a[expr]` 読み書き、未定義要素は 0。
- 動的成長 (疎な大インデックスはガード)。
- 配列要素への複合代入・インクリメント。

## 制御フロー

- `if` / `else`、`while`、`for` (各部省略可)、`break`、`continue`。
- ブロック `{ ... }`、空文。

## 関数

- `define name(params) { auto ...; body }`。
- スカラ仮引数 (値渡し)、`auto` ローカル (スカラ・配列)。
- 動的スコープ (退避/復元)、再帰、相互再帰。
- `return` / `return(e)` / `return e`、デフォルト戻り値 0。
- 関数の再定義。

## 組み込み

- `sqrt`、`length`、`scale`。
- `halt` / `quit`。

## 入出力

- 数値リテラルの `ibase` 解釈 (2–16、大文字数字)。
- `obase` 出力 (2–65535)。非十進の整数部・小数部・空白グループ化・先頭ゼロ抑制。
- bc 互換の 68 桁行折り返し (数値・文字列を通じグローバル列管理)。
- `print` (カンマ区切り・文字列エスケープ `\n \t \r \a \b \f \v \\ \q`、未知は無出力)。
- 裸の文字列文 (エスケープ非解釈でそのまま出力)。

## CLI / フレームワーク連携

- ファイル実行、標準入力実行、`-e EXPR`、tty で REPL (ブレース均衡まで蓄積)。
- 文単位の実行時エラー回復 (`setjmp`/`longjmp`; ゼロ除算等で次文へ継続)。
- `--plain` (純インタプリタ)、`--aot-compile` (実行時に文・関数本体を特殊化)。
- `--build OUT` (AST 埋め込み単体 exe; 関数定義なしのプログラム)。
- フレームワーク共通フラグ (`-q -v -h --version`)。

## テスト・ベンチ

- `bc` との差分テスト 5,500 ケース超 (厳選 + フィクスチャ + シード固定ファザ)。
- `bc` / abc-interp / abc-AOT の ~1 秒スケールベンチ (出力一致検証つき)。
