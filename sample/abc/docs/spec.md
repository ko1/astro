# abc 言語仕様

`abc` は POSIX `bc` および GNU `bc` 1.07 の挙動に合わせた任意精度電卓。本書は
実装した意味論を記す。実装済み/未実装の一覧は [done.md](done.md) / [todo.md](todo.md)。

## 数の表現

bc の数は **任意精度の十進固定小数点**:

```
値 = 仮数(mant) × 10^(-scale)
```

- `mant` は符号つき多倍長整数 (GMP `mpz_t`)
- `scale` は小数桁数 (>= 0)
- **末尾ゼロは有意**: `1.50` は `mant=150, scale=2` として保持され `1.50` と表示される
- ゼロは `scale` に関わらず `0` と表示される (`0.00` → `0`)

## 字句

- **数値リテラル**: `[0-9A-Z.]+`。大文字 `A`–`Z` は数字 (`A`=10 … `Z`=35) で、`ibase` に
  関わらず face value。小文字は識別子なので `ff` は変数、`FF` は数。
- **識別子**: `[a-z][a-z0-9_]*` (GNU 拡張のマルチ文字名)。
- **コメント**: `/* ... */` (複数行) と `# ...` (行末まで, GNU)。
- **文字列**: `"..."`。`"` で閉じる (`\"` エスケープは無い)。格納は**生のまま**。
- **行継続**: 行末 `\` + 改行は空白扱い。`(` `[` の内側では改行は無意味
  (式を複数行に分割できる)。`{}` の内側では改行は文の区切り。
- 改行と `;` が文の区切り。

## 演算子と優先順位 (緩い→きつい)

| 優先 | 演算子 | 結合 | 備考 |
|---|---|---|---|
| 1 | `=` `+=` `-=` `*=` `/=` `%=` `^=` | 右 | 左辺は lvalue (変数/配列要素) のみ |
| 2 | `\|\|` | 左 | 短絡。結果は 0/1 |
| 3 | `&&` | 左 | 短絡。結果は 0/1 |
| 4 | `!` | 単項 | |
| 5 | `==` `!=` `<` `<=` `>` `>=` | 左 | 連鎖可 (`1<2<3` = 1)。結果は 0/1 |
| 6 | `+` `-` | 左 | |
| 7 | `*` `/` `%` | 左 | |
| 8 | `^` | 右 | 冪。指数は整数に切り捨て |
| 9 | 単項 `-` | | `^` よりきつい: `-2^2` = `(-2)^2` = 4 |
| 10 | `++` `--` (前置/後置) | | lvalue のみ |

## scale (小数桁) の伝播規則

`S` を現在の `scale` 値とする。

| 演算 | 結果の scale |
|---|---|
| `a + b`, `a - b` | `max(scale(a), scale(b))` |
| `a * b` | `min(scale(a)+scale(b), max(S, scale(a), scale(b)))` |
| `a / b` | `S` (0 方向へ切り捨て) |
| `a % b` | `a - (a/b)*b`。scale は `max(S+scale(b), scale(a))` |
| `a ^ b` (b>=0) | `min(scale(a)*b, max(S, scale(a)))` |
| `a ^ b` (b<0) | `S` (= `1/a^|b|`) |
| `sqrt(x)` | `max(S, scale(x))` |

例:

```bc
scale=2; 10/3      # 3.33
scale=3; 10%3      # .001   (10/3=3.333, 3.333*3=9.999, 10-9.999=.001)
scale=5; 3*2.5     # 7.5    (scale = min(0+1, max(5,0,1)) = 1)
0.5^2              # .2     (scale = min(1*2, max(0,1)) = 1 → 0.25 切捨)
scale=6; 2^-3      # .125000
```

切り捨ては常に **0 方向** (`-5/3` = `-1`, `-7%3` = `-2`)。

## 特殊変数

| 名前 | 意味 | 範囲 |
|---|---|---|
| `scale` | 作業 scale | >= 0 |
| `ibase` | 入力基数 | 2–16 (範囲外はクランプ) |
| `obase` | 出力基数 | 2–65535 |
| `last` / `.` | 直近に**自動表示**された式の値 | |

代入時は整数へ切り捨て・クランプされる。これらは変数・関数の名前空間とは別。

## 文

- **式文**: 値を持つ式。**代入文でなければ**値を自動表示し改行する。
  - `x = 5` は表示しない。`(x = 5)` は括弧で式扱いになり表示する (bc と同じ)。
  - `x++` は表示する (代入ではないため)。
- **文字列文**: `"..."` 単体は**エスケープを解釈せず**そのまま出力 (改行を付けない)。
- `print e1, e2, ...`: カンマ区切りで出力 (改行なし)。文字列項は**エスケープを解釈**
  する (`\n` `\t` `\\` `\q`→`"`、未知の `\x` は何も出さない)。
- `if (cond) stmt [else stmt]`
- `while (cond) stmt`
- `for (init; cond; step) stmt` (各部省略可。cond 省略は真)
- `break` / `continue`
- `return` / `return(expr)` / `return expr`
- `{ stmt; stmt; ... }` ブロック
- `halt` / `quit` (実行時に終了)
- `define name(params) { auto locals; ... }` 関数定義

## 関数

- 仮引数はスカラ (値渡し)。本体先頭で `auto a, b, c` でローカルを宣言。
- **動的スコープ**: 呼び出し時に仮引数・auto の現在値を退避し、本体実行後に復元する
  (bc と同じ)。よって呼び出し先から呼び出し元の同名 auto が見える。
- `return` 省略時・値なし `return` は 0 を返す。
- 配列要素 `a[i]`、配列の auto 宣言 `auto a[]` をサポート。

## 組み込み関数

| 関数 | 意味 |
|---|---|
| `sqrt(x)` | 平方根 (scale = `max(S, scale(x))`、0 方向切り捨て) |
| `length(x)` | 有意桁数 (= `max(整数桁数, scale)`、最小 1) |
| `scale(x)` | `x` の scale |

`bc -l` の数学ライブラリ (`a`,`c`,`e`,`l`,`s`,`j`) は未実装 ([todo.md](todo.md))。

## 基数変換 (出力)

- `obase <= 16`: 数字 `0-9A-F`。整数部が 0 の純小数は先頭 0 を出さない (`.8` 等)。
- `obase > 16`: 各「桁」を `obase-1` の十進桁数で 0 詰めし空白区切り。整数部は各桁の
  前に空白 (先頭にも)、小数部は最初の桁のみ空白なし。例: `obase=1000; 123456` → ` 123 456`。
- 非十進の小数桁数は `obase^k >= 10^scale` となる最小の `k`。
  例: 2 進で `scale=1` の小数は `ceil(1·log10/log2)=4` 桁。

## 出力の行折り返し

bc 互換: 出力は 1 行 68 文字を超えると `\` + 改行で折り返す。列は文字列・数値を
通じてグローバルに数える (`print "abc"; 2^512` の数値は 65 桁目で折り返す)。
