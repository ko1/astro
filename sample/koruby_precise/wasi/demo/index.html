koruby_precise (wasm32-wasip1) in the browser

インタプリタ koruby.wasm (prelude 埋め込み済み、mount 不要) を @bjorn3/browser_wasi_shim で実行。 下のアニメーションで「wasm 実行中にブラウザが止まるか」が見える: JS 時計 = main thread (main-thread 実行中は止まる)、 CSS スピナー = compositor (止まらないことが多い)。 Worker 実行なら UI は一切止まらない。 起動: サンプルルートで python3 -m http.server → http://localhost:8000/wasi/demo/
