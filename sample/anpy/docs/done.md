# AnPy 実装済み機能

仕様は [spec.md](spec.md)、制限は [todo.md](todo.md)。

## 字句・構文
- インデント方式トークナイザ（NEWLINE/INDENT/DEDENT、タブ8桁、`( )`/`[ ]` 内は改行無視、
  空行・`#` コメント無視、文字列エスケープ `\" \\ \t \n`、`//` 演算子、整数 32bit 上限検査）。
- 全文法（program / classdef / funcdef / vardef / global・nonlocal / typedvar / type /
  stmt / 式の優先順位）の再帰下降パーサ。前方参照クラスを型注釈で使える。

## 型検査（§5.2）
- 型表現と適合 `<=`・代入互換 `<=a`・join `⊔`。
- 式の型推論: リテラル / 変数 / 算術 / 比較 / `is` / 論理 / 条件式 / リスト表示 /
  添字 / 属性 / 関数・コンストラクタ・メソッド呼び出し（arity + 引数互換 + 戻り型）。
- 文の検査: 代入（変数/属性/要素、代入互換）/ `if`・`while` 条件 bool / `for` 要素型 /
  `return` の戻り型互換。
- クラス構造: 親クラス存在・`int/bool/str` 継承禁止・継承の非循環。

## 実行（木構造インタプリタ）
- `int`/`bool`/`str`/list/オブジェクト/`None`、タグ付き VALUE、libgc。
- 算術（Python 床除算・床剰余）、比較、`is`、短絡論理、条件式。
- リスト: 生成・添字読み書き・連結・`len`・`for` 走査。文字列: 添字・連結・`len`・`for`。
- 変数・複数代入・グローバル/ローカル。
- 関数: グローバル / ネスト、`global`/`nonlocal`、再帰・相互再帰、クロージャ（捕捉環境）。
- クラス: 属性（継承込みスロット）、メソッド、`__init__`、単一継承、**動的ディスパッチ**、
  オーバーライド。
- 組み込み `print`/`len`/`input`。
- 実行時エラー（ゼロ除算・添字範囲外・`None` 操作・不正引数）と当該実行の中断。

## フレームワーク連携
- 統一 CLI 準拠（`--plain`/`--aot-compile`/`--build`/`-q`/`-v`/`-h`/`--version` は framework、
  固有は `--dump-ast`/`--no-typecheck`）。
- `--aot-compile`: トップレベル文 + 全関数/メソッド本体を SD 特殊化。
- `--build OUT`: AST 埋め込み単体 exe（関数定義なしのプログラム; [todo.md](todo.md)）。

## テスト・ベンチ
- `python3` との差分テスト + 実行時エラー + 型エラー拒否 + フィクスチャ（48 ケース）。
- `python3` / interp / AOT の ~1 秒ベンチ（出力一致検証つき）。
