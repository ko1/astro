# astrogre 言語仕様

`astrogre` は **正規表現 (regex)** エンジン。汎用プログラミング言語ではなく
**パターン記述用 DSL**。Ruby/Onigmo 互換の構文を採るので、Ruby の `/pat/`
リテラルで普段書ける範囲がそのまま動くと思って良い。

エンジンは grep スタイル CLI [`are`](../are/) のバックエンドとしても使える。
`are` の使い方とフラグ一覧は別ドキュメント。本書は **正規表現の構文と意味論**
のみを扱う。

## 正規表現とは

正規表現はテキスト中の「あるパターンに合う部分」を表現するミニ言語。
たとえば `\d+` は「1 文字以上の数字」、`[A-Z][a-z]*` は「英大文字 1 つに
続く英小文字 0 個以上」を意味する。astrogre では **パターン → AST →
ツリーウォーカ** という流れで照合する。

## リテラル形式

```
/pattern/flags
```

`pattern` は照合パターン本体、`flags` は挙動を変更する 1 文字フラグの集合。
たとえば `/foo[0-9]+/i` は「`foo` 直後に数字 1 文字以上、大文字小文字を
区別しない」。

| フラグ | 意味 |
|---|---|
| `i` | 大文字小文字を区別しない |
| `m` | `.` が改行にもマッチする |
| `x` | パターン中の空白とコメント (`#...`) を無視する (extended) |
| `n` | 入力を ASCII バイト列として扱う |
| `u` | 入力を UTF-8 として扱う (デフォルト) |

## 文字クラス

### 単純な文字

ほとんどの文字はそれ自体にマッチ。`a` は文字 `a` 1 つにマッチする。
特殊な意味を持つ記号 (`. * + ? ^ $ ( ) [ ] { } | \ /`) はバックスラッシュで
エスケープ: `\.` は文字 `.` にマッチ。

### `.` (任意の 1 文字)

`.` は改行 `\n` 以外の任意の 1 文字にマッチ (UTF-8 モードでは 1 codepoint)。
`/m` フラグを付けると改行にもマッチする。

### 文字集合 `[...]`

```
[abc]       # a, b, c のいずれか
[a-z]       # a から z まで
[A-Za-z0-9] # 範囲を複数並べる
[^0-9]      # 否定 (先頭の ^) — 数字以外
```

### 略記

| 略記 | 意味 |
|---|---|
| `\d` | 数字 (= `[0-9]`) |
| `\D` | 非数字 |
| `\w` | 単語文字 (= `[A-Za-z0-9_]`) |
| `\W` | 非単語文字 |
| `\s` | 空白 (空白・タブ・改行など) |
| `\S` | 非空白 |
| `\n` | 改行 |
| `\t` | タブ |
| `\r` | 復帰 |
| `\\` | バックスラッシュ |

## 量指定子 (quantifier)

直前の要素を何回繰り返すかを指定する。

| 量指定子 | 意味 |
|---|---|
| `*` | 0 回以上 (greedy) |
| `+` | 1 回以上 (greedy) |
| `?` | 0 または 1 回 (greedy) |
| `{n}` | ちょうど `n` 回 |
| `{n,}` | `n` 回以上 |
| `{n,m}` | `n` 回以上 `m` 回以下 |

末尾に `?` を付けると **lazy (非貪欲)** になる。greedy はできるだけ長く、
lazy はできるだけ短くマッチさせる:

```
"aaaa" にマッチ:
  /a+/   →  "aaaa"   (greedy)
  /a+?/  →  "a"      (lazy)
```

## アンカー (位置指定)

| アンカー | 意味 |
|---|---|
| `^` | 行頭 |
| `$` | 行末 |
| `\A` | 文字列の先頭 |
| `\z` | 文字列の末尾 |
| `\b` | 単語境界 |
| `\B` | 非単語境界 |

`^` `$` は通常「文字列全体の先頭/末尾」と「行頭/行末」を兼ねる (R 系言語の
慣習に沿う)。

## 選択 (alternation)

`|` で複数のパターンを並べ、いずれか 1 つにマッチさせる:

```
/cat|dog|bird/    # cat か dog か bird にマッチ
/(foo|bar)x/      # foox か barx にマッチ
```

## グループ化 と キャプチャ

### キャプチャ `(...)`

```
/(\d{4})-(\d{2})-(\d{2})/    # 年-月-日
```

マッチ後、グループ 1 = 年、グループ 2 = 月、グループ 3 = 日 として参照可能。

### 非キャプチャ `(?:...)`

グループ化だけしてキャプチャしない (高速・番号を消費しない):

```
/(?:foo|bar)x/     # foox/barx にマッチするが、グループ番号は使わない
```

### 名前付きキャプチャ `(?<name>...)` / `(?'name'...)`

```
/(?<year>\d{4})-(?<month>\d{2})/
```

### 後方参照 `\1` `\2` ... `\k<name>`

直前にキャプチャした内容と同じ文字列にマッチ:

```
/(\w+)\s+\1/          # 同じ単語が空白を挟んで 2 回繰り返す
/(?<x>\d+) (\k<x>)/    # 名前で参照
```

## 先読み (lookahead)

「位置」だけを照合し、文字を消費しない。

| 構文 | 意味 |
|---|---|
| `(?=...)` | 直後がパターンに合う |
| `(?!...)` | 直後がパターンに合わない |

```
/foo(?=bar)/    # "foobar" にはマッチ、"fooxx" にはマッチしない
                # ただし消費するのは "foo" のみ
/\d+(?!\.)/      # 数字列 (直後がピリオドではない)
```

(後読み `(?<=...)` `(?<!...)` は astrogre では未対応。)

## インラインフラグ

パターン途中でフラグを切替:

```
/(?i)Foo(?-i)bar/    # Foo は大小無視、bar は厳密
/(?i:Foo)bar/        # 局所的に i フラグを Foo にだけ適用
```

## extended (`/x`) モード

パターン中の空白とコメント (`#` 以降行末まで) を無視する。複雑なパターンを
読みやすく書ける:

```
/
  (\d{4})        # year
  -
  (\d{2})        # month
  -
  (\d{2})        # day
/x
```

## 例

```ruby
/foo/                       # "foo" にマッチ
/(\d+)/                     # 数字列にマッチ、グループ 1 にキャプチャ
/^\s*$/                     # 空白だけの行
/[A-Za-z_]\w*/              # 識別子
/<(\w+)>(.*?)<\/\1>/        # 単純な開閉タグ (lazy で内側最短)
/\b(?:if|else|while)\b/     # キーワード抽出
/(?<dir>[NSEW])(?<deg>\d+)/ # 方位 + 角度
```

## 入力エンコーディング

| 設定 | `.` の進み方 | 用途 |
|---|---|---|
| `--encoding=ascii` / `/n` | 1 byte | バイナリ入力、ASCII |
| `--encoding=utf-8` / `/u` (既定) | 1 codepoint | 通常のテキスト |

UTF-8 モードでは `é` のような複数バイト文字も 1 文字として扱う。`/é+/` は
`é` の繰り返しにマッチ (末尾バイトの繰り返しではない)。

## Unicode プロパティ

`\p{NAME}` はプロパティ NAME に属する 1 文字、`\P{NAME}` (= `\p{^NAME}`)
はその補集合にマッチする。名前は大小・`-`・`_`・空白を無視して引く。

| 種類 | 例 |
|---|---|
| general category | `\p{L}` `\p{Lu}` `\p{Nd}` `\p{Po}` `\p{Zs}` `\p{Cn}` |
| 長い名前 | `\p{Alpha}` `\p{Word}` `\p{Space}` `\p{Graph}` `\p{Assigned}` `\p{Any}` |
| script | `\p{Latin}` `\p{Han}` `\p{Hiragana}` `\p{Katakana}` `\p{Hangul}` ほか |

`[[:alpha:]]` 等の POSIX bracket class も UTF-8 モードでは Unicode 対応
(Ruby と同じ集合)。`/n` (バイトモード) では従来どおり ASCII のみ。

`\X` は拡張書記素クラスタ 1 個 (UAX #29)。絵文字 + 肌色 modifier、ZWJ
連結、Hangul jamo、Regional Indicator の対をひとまとまりとして扱う。

## サポートしない

- `/i` の Unicode 大文字小文字変換 (ASCII 範囲のみ)
- EUC-JP / Windows-31J エンコーディング
